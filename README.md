### إشراف مديرة المدرسة: أ. فريدة بنت سعود العتيبي

منظومة ويب متكاملة ومتطورة في إدارة، اعتماد، ومتابعة المبادرات النوعية لمعلمات **الثانوية الرابعة بالجبيل** وقياس أثرها التعليمي، التقني، والقيمي. صُممت المنصة وفق **الهوية البصرية الرسمية لوزارة التعليم** وهوية وشعار المدرسة المعتمد، وتعمل بمعمارية هجينة سحابية مؤمنة بنمط **Dark Glassmorphism** تجمع بين استضافة الواجهة على **GitHub Pages**، وخادم **Google Apps Script** المؤمن بمفتاح مصادقة (API Key)، وقواعد بيانات مشفرة بتقنية **SHA-256 مع Salt**.

## 🎨 الترقية التصميمية: نمط الزجاج الداكن (Dark Glassmorphism)

تمت ترقية لوحة التحكم والمتابعة بالكامل إلى نمط **Dark Glassmorphism** الفاخر، لتوفير تجربة بصرية رقمية متقدمة ذات تباين عالٍ وسهولة قراءة مريحة:
* **الخلفية العميقة المتدرجة:** خلفية كحلية داكنة (`#030712`) مع إضاءات هيدروجينية وتدرجات شعاعية من الأرجواني الداكن (`#53365D`) والتركواز الحيوي (`#25C7BC`) والبنفسجي الملكي (`#6E3884`).
* **بطاقات الزجاج الشفاف (Dark Glass Cards):** حاويات زجاجية مفرغة بتأثير الضبابية البصرية (`backdrop-filter: blur(16px)`) مع إطارات ناعمة ناصعة (`border-white/10`) وظلال غائرة تعكس العمق.
* **المخططات البيانية عالية التباين (Chart.js):** لوحة ألوان تفاعلية تتناغم مع الوضع الداكن: التركواز الحيوي (`#25C7BC`)، البنفسجي الملكي (`#6E3884`)، الأخضر الزمردي (`#07A869`)، الذهبي التعليمي (`#C1B48A`)، والأزرق السماوي (`#3D7EB9`) مع نصوص واضحة باللون الأبيض الرمادي.

## 🛡️ المعالجة الشاملة للمشكلات الأمنية والبرمجية المرصودة

تم إجراء تدقيق برمجي وأمني صارم ومعالجة كافة الثغرات الست المرصودة وتطبيق التحسينات الهندسية:

| :--- | :--- | :--- |

| **حماية الإدارة الوهمية والرموز الصريحة** في `admin.html` و`login.html` | 🔴 حرج | **حذف كافة الرموز الصريحة** (`1447` و `admin2026`). استبدال التحقق بمقارنة التجزئة الرقمية المشفرة (`Salted SHA-256 Hashes`) مع ملح تشفيري سري. كما تم استبدال القيمة البدائية `moe_school4_admin_authenticated` برمز جلسة موقع ومحمي تشفيرياً من أي تلاعب عبر DevTools. |
| **تخزين كلمات المرور كنصوص صريحة (Plain Text)** | 🔴 عالي | دمج وحدة التشفير القياسية **Web Crypto API**؛ حيث يتم تشفير كلمات مرور المعلمات بنمط **SHA-256 مع Salt عشوائي فريد لكل حساب** قبل حفظها محلياً أو في `initiatives_db.json`. تم حجب كلمات المرور من جداول الإدارة واستبدالها بوسام **"مؤمّن ومشفّر SHA-256 🔒"**. |
| **واجهة برمجة تطبيقات غير محمية (Unsecured API)** في `Code.gs` | 🔴 حرج | فرض **مفتاح مصادقة إلزامي (`API_KEY`)** في ترويسات وبارامترات كافة طلبات GET و POST. حجب أي طلب غير مصرح به تلقائياً. تعقيم مخرجات GET لحجب تجزئات كلمات المرور من الاستجابة العامة. |
| **هشاشة قاعدة البيانات وغياب المزامنة التلقائية** | 🟠 متوسط | تطوير نظام **المزامنة المركزية السحابية (Live Sync & Offline-First)**: عند فتح المنصة، يتم إرسال طلب `GET` فوري لجلب وتحديث المبادرات وسجل المعلمات من Google Sheets سحابياً مع الاحتفاظ بنسخة محلية للعمل دون اتصال. |
| **تسريب أسماء المستخدمين (User Enumeration)** في `login.html` | 🟠 متوسط | **حذف دالة ومربع `renderQuickTeachers` كلياً** من صفحة تسجيل الدخول، ومنع أي كشف مسبق لأسماء المعلمات المسجلات قبل تسجيل الدخول لضمان الخصوصية وسرية الحسابات. |

## 📊 نظام التصدير المتقدم: عروض PowerPoint التفاعلية (`PptxGenJS`)

تم دمج مكتبة **PptxGenJS** في لوحة الإدارة لتمكين مديرة المدرسة **أ. فريدة بنت سعود العتيبي** من استخراج عروض تقديمية رسمية تفاعلية بضغطة زر واحدة:

* **شريحة الغلاف الرسمية الفخمة:** متوافقة مع الهوية الوزارية للتعليم بالمنطقة الشرقية، اسم الثانوية الرابعة بالجبيل، إشراف مديرة المدرسة، والتاريخ الرسمي.
* **شريحة مؤشرات الأداء العليا (Executive KPIs):** بطاقات ملونة بنسب المبادرات المكتملة، قيد التنفيذ، المعتمدة، والمتميزة، مع جدول تفصيلي للمسارات الخمسة.
* **شرائح سجل المبادرات المعتمدة:** جداول منسقة بدقة بنمط عريض (16:9) مع دعم كامل للغة العربية (RTL) تتضمن أسماء المعلمات، المسارات، نسب الإنجاز، وحالة الاعتماد وروابط الشواهد.

## 👩‍🏫 مهام المعلمة وطريقة التسجيل ورفع المبادرة

```
[تسجيل الدخول / حساب جديد] ───► [تعبئة الأهداف والبيانات] ───► [إرفاق رابط الشواهد السحابي] ───► [متابعة رحلة الإنجاز]
```

### 1️⃣ تسجيل حساب جديد:
1. الدخول عبر صفحة [`login.html`](file:///c:/Users/Legion/Documents/antigravity/adventurous-rutherford/login.html).
2. إدخال: **اسم المعلمة بالعربية**، **اسم المستخدم بالإنجليزية** (مثال: `sara_h`)، **التخصص**، و**كلمة السر**.
3. يتم تشفير كلمة المرور فوراً بـ Salt و SHA-256، وإنشاء جلسة موثقة ونقلها مباشرة إلى مساحة المبادرات.

### 2️⃣ رفع المبادرة وإرفاق الرابط:
* تتوجه المعلمة إلى تبويب **"+ أضيفي مبادرة نوعية"**:
  * ملء عنوان المبادرة، المسار (تعليمي، تقني، قيمي، بيئي، مهني)، الفئة، والمستفيدين.
  * **إرفاق الرابط السحابي (أساس التوثيق):** وضع رابط Google Drive أو OneDrive أو Canva الخاص بشواهد المبادرة مع التأكد من تفعيل صلاحية العرض.
  * حفظ وإرسال المبادرة للإدارة للمراجعة والاعتماد.

### 3️⃣ مهام المعلمة بعد التقديم:
* متابعة قرار الاعتماد وملاحظات المشرفة المدونة على بطاقتها.
* تحديث **نسبة الإنجاز (Progress %)** دورياً بنقرة زر.
* طباعة الملف الرسمي للمبادرة من صفحة [`initiative-view.html`](file:///c:/Users/Legion/Documents/antigravity/adventurous-rutherford/initiative-view.html) وإدراجه في ملف الإنجاز.

## 🔐 منظومة استعادة كلمة السر الآمنة

1. عند نسيان كلمة المرور، تضغط المعلمة على **"نسيتِ كلمة السر؟"** في صفحة الدخول.
2. ترفع طلباً إلكترونياً باسمها/اسم المستخدم وكلمة السر الجديدة المطلوبة.
3. يظهر إشعار فوري وماض وشريط تحذيري في لوحة الإدارة (`admin.html`).
4. تضغط مديرة المدرسة على **"اعتماد وتغيير"**؛ فيقوم النظام فورياً بحساب ملح تشفيري جديد وتجزئة SHA-256 لكلمة المرور وحفظها في قاعدة البيانات دون تخزينها بنص صريح.
5. تستطيع المعلمة تسجيل الدخول فوراً بكلمة السر الجديدة.

## 🚀 دليل النشر والتشغيل على GitHub Pages

### الخطوة 1: تهيئة المستودع ورفع الملفات
1. أنشئي مستودعاً جديداً على GitHub باسم `sec4-initiatives`.
2. ارفعي الملفات الأساسية التالية إلى الفرع الرئيسي (`main`):
   * `index.html` (بوابة المعلمات)
   * `login.html` (بوابة الدخول الموحدة)
   * `admin.html` (لوحة الإدارة - Dark Glassmorphism)
   * `initiative-view.html` (وثيقة الطباعة والتوثيق)
   * `initiatives_db.json` (قاعدة البيانات المشفرة)
   * `logo.png` (شعار الثانوية الرابعة المعتمد)
   * `Code.gs` (كود خادم Google Apps Script)

### الخطوة 2: تفعيل استضافة GitHub Pages
1. ادخلي على إعدادات المستودع **Settings** ➔ **Pages**.
2. تحت قسم **Build and deployment** اختاري:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` / `root`
3. اضغطي **Save**. سيظهر لكِ الرابط المباشر للمنصة خلال دقائق معدودة:
   `https://<username>.github.io/sec4-initiatives/`

### الخطوة 3: تفعيل الربط السحابي مع Google Sheets (اختياري للمزامنة الحية)
1. افتحي جدول Google Sheets جديد باسم `قاعدة بيانات الثانوية الرابعة بالجبيل`.
2. من القائمة العلوية: **الإضافات (Extensions)** ➔ **Apps Script**.
3. الصقي محتويات ملف [`Code.gs`](file:///c:/Users/Legion/Documents/antigravity/adventurous-rutherford/Code.gs).
4. اضغطي **Deploy** ➔ **New deployment** ➔ اختاري نوع **Web app**.
5. حددي الصلاحيات: **Who has access:** `Anyone`.
6. انسخي رابط الـ Web App الناتج، وضعيه في إعدادات المنصة. مفتاح API الافتراضي هو: `SEC4_JUBAIL_API_KEY_2026`.

## 👥 نظام الربط والاكتشاف التلقائي لحسابات المعلمات (Auto-Harvesting & Dynamic Sync)
* **المزامنة الحية:** بمجرد تسجيل أي معلمة لمبادرة جديدة أو إضافتها من قبل الإدارة، يتم استكشاف اسمها واسم المستخدم تلقائياً وربطها فوراً في "سجل حسابات المعلمات والمستخدمين".
* **الدمج غير الهدّام:** عند استيراد قواعد بيانات JSON أو تفعيل النماذج المعتمدة، يتم دمج الحسابات والمبادرات دون مسح أو استبدال أي معلمة مسجلة مسبقاً.
* **زر الاستكشاف اليدوي:** متاح في أعلى جدول المعلمات عبر زر `مزامنة واكتشاف المعلمات` لإعادة فحص وتجميع كافة المعلمات من سجل المبادرات والطلبات بضغطة زر.
